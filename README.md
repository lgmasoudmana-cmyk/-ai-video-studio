# AI Video Studio — iPhone Ready

وب‌اپ چندصحنه‌ای برای تولید ویدئو با Runway Gen-4.5.

## Deploy on Render

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Add environment variable: `RUNWAYML_API_SECRET` = your Runway API key

The app serves its iPhone-friendly UI directly from `server.js`, so no `public/` folder is required.
